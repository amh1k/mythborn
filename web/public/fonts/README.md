# Mythborn typography

Fonts are hosted locally. Licenses are shipped alongside each family.

| Family | Use | Files |
|---|---|---|
| Uncial Antiqua | Wordmark, page titles, hero headlines, founding plate, decorative initial | `uncial-antiqua.ttf` |
| Almendra | Section headings, world names, agent names, chronicle text, italic suggestions | `almendra-regular.ttf`, `almendra-bold.ttf`, `almendra-italic.ttf` |
| DM Sans | Navigation, forms, labels, controls, explanations | `dm-sans-regular.ttf`, `dm-sans-semibold.ttf` |

## Sources and inspiration

- [Pentiment official site](https://pentiment.obsidian.net/): manuscript and woodcut art direction; its accessibility discussion also reinforces keeping functional text legible.
- [Kingdom Come: Deliverance II official site](https://www.deepsilver.com/games/kingdom-come-deliverance-ii): medieval setting and dramatic scene presentation.
- [Uncial Antiqua](https://fonts.google.com/specimen/Uncial+Antiqua), [official description](https://github.com/google/fonts/blob/main/ofl/uncialantiqua/DESCRIPTION.en_us.html).
- [Almendra](https://fonts.google.com/specimen/Almendra), [official description](https://github.com/google/fonts/blob/main/ofl/almendra/DESCRIPTION.en_us.html).

These are design references, not claims that the reference sites use these exact fonts. Mythborn uses its own font pairing and local assets.
