# Mythborn identity

The identity pairs a custom letterpress M with a lowercase Almendra wordmark. The initial uses tapered stems, broad feet, and a low central meeting point. Its open silhouette replaces the previous framed mountain badge.

- `mythborn-mark.svg` is the shared source for the interface mark and favicon.
- The interface renders it as a CSS mask, inheriting the surrounding ink color. On dark artwork it uses the same light color as the wordmark.
- The standalone favicon switches between dark ink and ivory using the system color preference.
- Keep the mark monochrome and unboxed. Do not add a colored dot, outline frame, glow, or decorative separator.
- Keep the wordmark lowercase, with its existing spacing and proportions. Its readable link name is “mythborn”; the adjacent mark is decorative for screen readers.
- Almendra's license is bundled under `public/fonts/`.
